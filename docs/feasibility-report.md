The first full attempt ended at 21:51 CEST after 22,628 seconds, with 52,872 completed actions and one failed Prism object: `credential_store_linux.o`. Chromium's bundled libsecret header requires an enum constant for the schema terminator, and `base::NoDestructor` rejects the trivially destructible dynamic-loader holder. Both were corrected in Prism-owned code. Incremental compilation then exposed Chromium Clang-plugin style errors in the host-only broker header, an `override` omission, the pinned revision's renamed `base::DictValue` and `base::ListValue` APIs, an updated `SimpleURLLoader` callback type, and incomplete type and namespace qualifications. The revised `//prism/ai:core`, `//prism/ai:chromium`, `//prism/ui/webui:prism_ai_ui`, and `//prism/credentials:credentials` targets compile, and `gn check` passes for the latter three. The incremental `chrome` build succeeded at 22:51 CEST in 55m42s with 4,014 further actions. Its final WebUI fix relinked successfully, and `python3 scripts/phase0/browser_smoke.py /home/pawel/coding/prism-chromium-work/chromium/src/out/PrismFeasibility/chrome` passed for both an ordinary local page and `chrome://prism-ai/`. The WebUI uses a regular `DefaultWebUIConfig` because `DefaultInternalWebUIConfig` is gated behind Chromium's developer-only debug-page switch; it serves its three generated assets through `WebUIDataSource::SetRequestFilter`. An immediate first navigation to the custom URL can race Chromium's startup registration in headless mode, so the smoke probe opens `chrome://version/` first and then navigates to Prism.

The Store candidates are [uBlock Origin Lite](https://chromewebstore.google.com/detail/ublock-origin-lite/ddkjiahejlhfcafbddmgiahcphecmpfh?hl=en), listed at version `2026.1006.1931` on 2026-10-09, and [Dark Reader](https://chromewebstore.google.com/detail/dark-reader/eimadpbcbfnmbkopoojfekhnkhdbieeh?hl=en), listed at `4.9.133`. In the built browser, both Store listings loaded after rejecting the temporary profile's Google consent dialog. The Store displayed a recommendation to switch to Chrome. Clicking **Add to Chrome** for uBlock Origin Lite made the button disappear, but `chrome.developerPrivate.getExtensionsInfo()` returned no installed extension five seconds later. This is an attempted install with an unresolved browser confirmation step, not an install pass; neither extension's function, restart, or update was verified.

`npm run test:extension-persistence -- /home/pawel/coding/prism-chromium-work/chromium/src/out/PrismFeasibility/chrome` passed for the in-repo MV3 fixture `cfehneehpnafmkejjgemgigeljbemmhn`: its `chrome.storage.local` value survived a browser restart in the same temporary profile. Playwright's default `--disable-extensions` flag had to be removed, and the test now queries `chrome.developerPrivate.getExtensionsInfo()` instead of assuming a command-line extension has a complete `Preferences` record while running. The fixture was loaded through `--load-extension` on both runs. A separate restart without that flag showed the extension absent, so this result proves storage persistence under reloading, not persistence of a normally installed extension. No public extension version or updater behavior is claimed.

Starting the built browser with `--auto-open-devtools-for-tabs` produced `devtools://` targets titled `DevTools`, confirming that the standard frontend is linked. CDP-synthesized F12 did not open the browser window's DevTools, and XTest key events did not reach the Chromium window under this host's Wayland session. F12, Elements, and Console therefore remain unverified by direct interaction.

## Decisions and limitations

- Phase 0 stays on full Chromium; Electron, CEF, Qt WebEngine, and packaged Chromium are excluded from build proof.
- The pinned checkout has a one-line Prism dependency in `chrome/browser/BUILD.gn` and two narrow WebUI patches; see `docs/upstream-patches.md`. The AI session is linked in the browser; only the WebUI startup and asset loading, not a real AI conversation, have been exercised.
- This Linux host exceeds the documented minimum memory but is below Chromium's recommended >16 GiB; the first build uses four parallel jobs.
- A native Windows host and a developer OpenAI API key are independent requirements to close the corresponding gates.
- The checkout and tools remain under `/home/pawel/coding/prism-chromium-work`; the Linux binary has passed the ordinary-page and Prism WebUI smoke tests. The build was incremental after the initial compiler failure rather than a second clean build.
